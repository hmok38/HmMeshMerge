# Hm Mesh Merge

把共享同一 Shader 的多个模型合并为一个 Mesh 和一个材质，顶点记录来源索引；绘制时选择其中一个来源。插件不负责实例批次组织，单独合并 Mesh 不保证减少 draw call。

## 使用

1. 打开 Tools/HmMeshMerge/网格合并，新建或选择保存在 Assets 内的配置资产。
2. 添加 Mesh 与 Material。顺序就是来源索引，位置保持各源网格的局部坐标，不做排列偏移。
3. 点击“按源着色器列出属性”。首次把不同值排前并启用，相同值排后并停用；以后只追加新项，保留旧行号和选择。贴图 Tiling/Offset 以属性名加 _ST 加入候选。
4. 选择所有源均未占用的索引通道，默认 **UV3（TEXCOORD3，零基编号）**。
5. 执行合并。纹理宽高、实际格式（含 sRGB）、mip 或采样设置不同会报错并给出建议值，**由用户手动统一，插件不修改源贴图**；每张需要修改的来源贴图各输出一条日志（同一贴图只输出一次），单击该条目即可在 Project 中定位对应贴图，最后再输出一次汇总——按贴图列出各层参数与建议，引用同一组贴图的属性共用一条。
6. 使用输出 Mesh 和 Material，以材质属性或 MaterialPropertyBlock 的 _MeshMergeIndex 选择来源。生成 Shader 中的逐属性函数可复制到自有 Shader。

配置与结果都记录在同一个 HmMeshMergeAsset。停用参数使用第一来源的普通材质值，旧 LUT 行空出；只有显式“重新整理参数表”改变已有行号。改源材质数值后需要再次合并。

## 输出与数据契约

| 输出 | 内容 |
|---|---|
| _Mesh.asset | 源局部顶点、法线、切线、顶点色、UV0–UV7；额外写入来源索引 |
| .hmtexarray | 启用且贴图引用不同的二维贴图属性各一份数组，层号就是来源索引 |
| _Params.asset | 按需生成的 RGBAFloat、线性、无压缩、无 mip LUT；X 为来源索引，Y 为稳定参数行 |
| _Shader.shader | URP 无光照展示和接入模板，逐个属性生成读取函数 |
| _Material.mat | 绑定普通源属性、纹理数组和 LUT |

- 不再将数值夹到 0–1；Float、Range、Vector、Color、Integer 按类型读取。整数超出 Float 精确表示能力时报错。Color 在 Linear 项目中转换为线性值写入 LUT，其他数值不转换。
- 同一张贴图不生成数组；未启用的不同参数也明确使用第一来源的值。
- 纹理数组用源贴图的每层 mip 原始数据保存，需手动开启 **Read/Write**，不支持 Crunch。导入器记录产物依赖；源贴图导入变化后数组随之重导。Android 实际格式与体积仍需人工出包核验。
- 已有 Mesh、Material 和浮点 LUT 原地更新并保留 GUID。旧版本的 _Params.png 不自动删除；重新合并后材质会改绑 _Params.asset。
- 非三角形、蒙皮、BlendShape 会明确报错；请先烘焙成静态网格。多个子网格可合并，但每个来源只有一个材质，所有子网格使用该材质。
- 缺失的 UV/法线/切线补零，缺失顶点色补白；已有数值保留，合并后的顶点存储格式可能改变。基于顶点编号而非 UV/颜色的动画需要使用者自行适配。

## Shader 接入

生成模板自动识别 MainTexture / MainColor 标记或 _BaseMap / _MainTex、_BaseColor / _Color 作基础展示；有 _Cutoff 时示范 Alpha 裁剪，有 _AlphaClip 时受其控制。这些仍是普通参数表项，没有独立配置字段。

生成的 HmRead 和 HmSample 函数包含实际行号及贴图取法。三个 Pass 统一处理来源选择和 Alpha 裁剪。模板不重现源 Shader 的光照、透明混合、法线解码或其他专有效果。

生成模板对 `HmMeshMerge.hlsl` 的 `#include` 按工具运行工程里包的实际安装路径写入（嵌入包是 `Packages/<目录名>`，git 或本地安装是 `Packages/<包名>`），不写死包名。示例 Shader 是静态文件，路径固定为包名 `com.hm.meshmerge`，改名后需同步修改。

合并数据不依赖宿主项目或实例化框架。**当前生成模板与示例针对 URP**；其他管线需移植数据读取和索引判断。默认实例属性路径不承诺 SRP Batcher 兼容。矩阵 m33 编码仅保留为自定义渲染路径接口，不能把编码矩阵当作标准 TRS 使用。

完整职责和失败边界见 [设计说明](Documentation~/Design.md)。
