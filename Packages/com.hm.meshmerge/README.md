# Hm Mesh Merge

把多个共享同一 Shader 的模型合并成 1 个 Mesh 与 1 个材质：每个顶点带“来源索引”，绘制时按索引只显示其中一个来源。用于把“多品种、每品种少量实例”的绘制合批，降低 draw call。

## 状态

包骨架已建立，合并工具与运行时部分实现进行中。设计与数据契约见 [Documentation~/Design.md](Documentation~/Design.md)。

## 安装

本包作为嵌入包（embedded package）开发于宿主项目的 `Packages/com.hm.meshmerge/`。其他项目可通过 Git URL 或本地路径引用。

## 数据契约摘要

| 载体 | 内容 |
|---|---|
| TEXCOORD0 | UV（原样保留：贴图走纹理数组，不重映射） |
| 索引通道（默认顶点色） | 来源索引，0..N-1；顶点色为 8 位，该通道下来源数上限 256 |
| 材质 `_<贴图属性>` | 每个贴图属性一个纹理数组，**层号即来源索引**；由 `.hmtexarray` 导入器生成，切平台时随源贴图按平台重导 |
| 材质 `_HmMeshMergeParams` | 数值参数的查找纹理：横轴为来源索引，纵轴为参数表的行 |
| 激活索引 | 每次绘制要显示哪一个来源，由使用者的渲染路径传入 |

合并网格只写索引，UV 不动；贴图与参数都按来源索引取。数值参数的读取由 `HmMeshMerge.hlsl` 的 `HmMeshMergeLoadParam(纹理, sourceIndex, 行号)` 提供，行号记在合并资产的参数表里、也列在生成着色器的文件头。该着色器基于 URP。

## 边界

不提供渲染器、不做批次管理与剔除、不绑定任何具体合批技术；不假设宿主项目的资源系统与目录结构。生成的着色器只做无光照展示（按来源索引采样纹理数组的对应层，并取参数表第一个启用行乘到颜色上），不还原源着色器的光照效果。
